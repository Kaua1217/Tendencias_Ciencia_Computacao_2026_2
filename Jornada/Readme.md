## 🚀 Missão 01 — Decolagem Imediata

Como primeira atividade da disciplina, foi proposta a **Missão 01 — Decolagem Imediata**, realizada durante a aula inaugural.

### 🎯 Desafio

1. Criar um prompt simples;
2. Compartilhar o resultado no README do repositório da disciplina.

### 💬 Meu Prompt

> Explique o que é Inteligência Artificial de forma simples, como se estivesse explicando para uma pessoa que nunca teve contato com tecnologia.

### 🤖 Resultado

A Inteligência Artificial (IA) é uma tecnologia que permite que computadores e sistemas realizem tarefas que normalmente exigiriam inteligência humana, como compreender textos, reconhecer imagens, aprender com informações, identificar padrões e tomar decisões.

### 💡 Reflexão

A criação desse primeiro prompt permitiu observar como a forma de escrever uma instrução pode influenciar o resultado produzido por uma ferramenta de Inteligência Artificial.
